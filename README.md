# Message-Board-Web-Server-python
This project was getting a web server that you can host for a Message Board for clients to connect to 

## How to run

To host this web server you need to run the command like this `python3 HTTPServer.py`.

This will allow clients to connect to the message board from your IP and using port 33920.


## How to use 

To use this web server you need to log in or register with credentials first then you will be handed a session cookie back and be logged in.

You can post messages onto the board and see what others have posted and you can filter by last couple messages as well.
